# Démos Kira Labs

Prototypes cliquables que Kira Labs montre à ses clients et prospects. **Ce repo est public** et publié sur GitHub Pages : `https://kiralabs-fr.github.io/kiralabs-demos/<client>/`.

## Règles
- Un dossier par client (slug du repo client), avec un `index.html` autonome.
- **Données fictives uniquement.** Jamais de vraies données client, de transcript, de prix ni de note interne : tout ici est visible par n'importe qui.
- Chaque page porte `<meta name="robots" content="noindex, nofollow">` pour ne pas être référencée.
- La source et le contexte d'une démo restent dans le repo du client (privé).
